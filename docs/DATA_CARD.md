# Data card: ADHYAKSH intent dataset

## Files
- data/intents.csv: 1208 training rows. Columns: text, intent, language, script, source, reviewed.
- data/test_codemixed.csv: 144 held-out code-mixed rows (hinglish and gujlish, Latin script). Never used for training or threshold tuning.

## How it was made
Rows are generated by adhyaksh/nlu/dataset.py from hand-written templates and small slot lists (file names, application names, personal names, facts, topics), then lightly varied (polite prefixes and suffixes, random lowercasing). Run `python -m adhyaksh.nlu.dataset generate` to rebuild. All rows have source=generated and reviewed=false. NOTHING HAS BEEN REVIEWED BY A NATIVE SPEAKER. Hindi and Gujarati text may contain unnatural phrasing or grammar (for example gender agreement in "mera/meri").

## Coverage
18 intents, 40 to 70 rows each (greet has 48). Five language groups with about 240 rows each: English, Hindi (Devanagari), Gujarati (Gujarati script), Hinglish and Gujlish (romanized). The held-out code-mixed file uses different sentence frames and different topic words from the training templates.

## Known limitations and biases
- Synthetic and template-driven: the in-distribution test score is optimistic because train, validation and test rows share templates. Treat the code-mixed score as the more honest estimate, and expect lower accuracy on real user text.
- Small slot vocabularies: about 10 personal names (mostly Indian), 12 file names, 7 application names.
- Romanized spelling is not standardized; only a few variants are covered.
- Intent "unknown" is a small set of fillers and nonsense strings; it does not represent all out-of-scope requests.
- Personal facts in the data are invented.
